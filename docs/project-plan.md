# AI FINAL PROJECT – PROJECT PLAN

## 1. Project Information

- **Course:** 503043 – Introduction to Artificial Intelligence
- **Project:** AI Final Project
- **Duration:** 06 weeks
- **Programming Language:** Python
- **IDE:** Visual Studio Code
- **Version Control:** Git and GitHub

## 2. Project Objectives

The project aims to apply artificial intelligence algorithms to solve three problems:

1. N-Queens using Propositional Logic, SAT Solving, and Local Search.
2. Tank Battle Game using Adversarial Search.
3. Kakuro using Constraint Satisfaction Problems.

The project also requires experimental evaluation, graphical user interfaces, technical documentation, and a final IEEE report.

## 3. Project Tasks

### Task 1 – N-Queens

**Topics:**
- Propositional Logic
- Conjunctive Normal Form (CNF)
- SAT Solver
- Glucose3 (PySAT)
- Min-Conflicts
- Heuristic Optimization

**Deliverables:**
- Mathematical formulation
- CNF generation
- Glucose3 solver
- Standard Min-Conflicts solver
- Improved Min-Conflicts heuristic
- Experimental results and comparisons

### Task 2 – Tank Battle Game

**Topics:**
- Zero-Sum Games
- Minimax Search
- Alpha-Beta Pruning
- Heuristic Minimax Search
- PyGame

**Deliverables:**
- Game model and rules
- Game engine
- Four AI search configurations
- Experimental performance comparison
- Graphical user interface
- External algorithm integration mechanism

### Task 3 – Kakuro

**Topics:**
- Constraint Satisfaction Problems
- Variables and Domains
- Constraints
- Constraint Propagation
- Backtracking Search
- Heuristics

**Deliverables:**
- CSP formulation
- Kakuro solver
- Constraint propagation
- Backtracking Search
- Complex test case evaluation
- Graphical visualization of the solving process

### Task 4 – Report and Interview

**Deliverables:**
- IEEE conference report
- Contributions
- Self-evaluation
- Conclusion
- References
- Demo video
- Interview preparation

## 5. Development Principles

- Apply Object-Oriented Programming principles.
- Use modular code organization.
- Maintain version control with Git and GitHub.
- Separate implementation, testing, and experimental results.
- Record actual experimental configurations and measurements.
- Preserve all outputs in Jupyter Notebook files.
- Maintain documentation for installation and execution.

## 6. Completion Criteria

The project is considered complete when:

- All three technical tasks satisfy their specified requirements.
- All required algorithms are implemented and tested.
- Experimental results are reproducible and documented.
- Graphical interfaces operate correctly.
- The IEEE report satisfies the formatting and length requirements.
- The demo video is available.
- All submission materials are correctly packaged.
