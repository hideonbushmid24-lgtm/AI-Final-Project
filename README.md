# Introduction to Artificial Intelligence - Final Project

## Project Overview

This project is developed for the Introduction to Artificial Intelligence course.

## Project Tasks

### Task 1: N-Queens
- Propositional Logic
- CNF
- Glucose3 SAT Solver
- Min-Conflicts

### Task 2: Tank Battle Game
- Zero-Sum Game
- Minimax Search
- Alpha-Beta Pruning
- Heuristic Minimax
- PyGame

### Task 3: Kakuro
- Constraint Satisfaction Problems
- Constraint Propagation
- Backtracking Search
- Heuristics
- Graphical User Interface

## Technologies

- Python
- PySAT
- PyGame
- Visual Studio Code
- Git and GitHub

## Project Structure

- source/task1: N-Queens
- source/task2: Tank Battle
- source/task3: Kakuro
- source/data: Test data
- source/notebooks: Jupyter notebooks
- source/results: Experimental results
- report: IEEE report files
- docs: Project documentation

## Installation
